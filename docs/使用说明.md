## 1. 安装与启动

**系统要求**

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（本地终端要 Windows 10 1809 或更高） |
| 运行时 | .NET Framework 4.8（Win10/11 自带） |
| 终端 / SSH | Microsoft Edge WebView2 运行时（Win11 自带，缺失时程序会给出下载链接） |
| 录屏 | Windows N 版需要先装“媒体功能包” |
| AI 助手 | 需要联网下载 pi，并准备自己的模型 API Key 或订阅 |

**安装**：把发布包解压到任意文件夹（例如 `E:\SeedToolBox`），运行 `SeedToolBox.exe`。不需要安装程序，也不写系统目录。

**便携**：所有配置都保存在程序旁边的 `Data\` 文件夹。整个文件夹拷走，配置就一起带走。

**只运行一份**：程序已经在运行时，再次打开 exe 会把已有的主窗口调到前面。

**开机自启**：在「设置 → 常规」勾选「开机自动启动（在后台运行）」。开机后只在托盘运行，按 `Ctrl+Q` 呼出。

## 2. 界面概览

程序有三个入口：

- **主窗口（启动器）**：按 `Ctrl+Q` 呼出。上方是搜索框，中间是你的快捷方式，下方一排快捷按钮：截图、录屏、识字、取色、剪贴板、便签、开发工具、提醒、系统监控、声音亮度、AI 助手、全部工具、终端 / SSH。
- **工具箱窗口**：点「全部工具」打开。左侧是分组侧边栏（可以收起），底部是「设置」。
  - 顶层页面：快速笔记、剪贴板、截图历史、颜色、提醒、AI 操作记录、AI 插件和技能。
  - **格式与编码**：代码格式化、数据格式互转、编码转换、Base64 编解码、时间戳/进制。
  - **开发调试**：正则测试、文本对比、JWT 解码 / 校验、哈希校验、UUID/密码、API 请求、终端 / SSH。
  - **图片**：图片格式转换、图片 Base64。
  - **文件**：批量重命名、重复文件、空间占用、文件压缩。
  - **系统与网络**：端口/网络、Hosts 管理。
  - **系统工具**：保持唤醒、窗口置顶、环境变量、启动项、进程、本地服务、系统监控、声音与亮度。
- **托盘图标**：右键菜单里有截图、识别文字、录屏、剪贴板历史、暂停记录剪贴板、新建便签、快速笔记、工具箱、提醒、终端 / SSH、AI 助手、系统工具、设置、退出。菜单项旁边会显示对应快捷键。

## 3. 全局快捷键

| 功能 | 默认快捷键 |
|---|---|
| 呼出主窗口 | `Ctrl+Q` |
| 截图 | `Alt+Shift+A` |
| 录屏（开始 / 停止） | `Alt+Shift+E` |
| 剪贴板历史 | `Alt+Shift+V` |
| 新建便签 | `Alt+Shift+N` |

以下功能默认没有快捷键，需要的话在「设置 → 更多快捷键（默认未设置）」里设置：

- **截图与识别**：打开快速笔记、全屏截图、窗口截图、上次区域截图、延时截图、贴图穿透开关、取色、屏幕标尺、识别文字、识别表格、识别二维码。
- **AI**：打开 AI 助手、AI 处理选中文字、截图问 AI。
- **系统工具**：切换当前窗口置顶、显示/隐藏系统监控、切换系统监控鼠标穿透、切换到下一个输出设备、麦克风静音、亮度 +10 / -10。

**修改方法**：点输入框，直接按下想要的组合键；点「清除」可取消。

- 和程序里其他功能重复时，会提示已被哪个功能占用。
- 被别的程序占用时，托盘会弹出提示，换一个组合即可。
- 启动器里的每个项目也可以单独「设置快捷键…」。

## 4. 启动器

### 添加快捷方式

- 把程序、快捷方式、文件夹或网址直接**拖进**主窗口。
- 或者右键空白处 →「添加程序/文件...」/「添加网址...」（网址要以 http:// 或 https:// 开头）。
- 在搜索结果里找到系统已安装的应用，右键「添加到启动器」。

### 管理

- **右键项目**：打开、以管理员身份运行、打开文件位置、属性...（改名称、参数、工作目录、图标、备注）、设置快捷键…、重命名、删除。删除只删快捷方式，不删原文件。
- **拖动**可调整顺序。
- **分组**：新建分组、重命名分组、删除分组，至少保留一个分组。
- **视图**：大图标 / 小图标 / 列表。
- 常用的项目会按使用次数排在前面。

### 搜索框

搜索框同时搜启动项和系统里已安装的应用，**支持拼音**（输入 `wx` 能找到“微信”）。还支持这些前缀：

| 输入 | 作用 |
|---|---|
| `=2^10+sqrt(9)` | 计算器，回车复制结果 |
| `>ipconfig` | 在新的命令行窗口运行命令 |
| `g 关键词` / `bd 关键词` / `bing 关键词` | 用 Google / 百度 / 必应搜索 |
| `f 文件名` | 查找文件，回车打开，Ctrl+回车打开所在文件夹。装了 Everything 会自动用它 |
| `t 名称` | 查找工具箱里的工具 |
| `ai 问题` | 问 AI |
| `ai 帮我…` / `do …` | 交给 AI 自动化去做 |
| `10分钟后 喝水` | 直接添加提醒 |

## 5. 截图、贴图与屏幕工具

### 截图

按 `Alt+Shift+A`，拖出区域，或者直接点选窗口。

- **截图时的按键**：
  - `F` 全屏，`W` 窗口，`R` 上次区域
  - `O` 识字，`Q` 扫码，`C` 复制鼠标处颜色
  - 右键或 `Esc` 退出
- **尺寸**：可以锁定比例，或直接输入尺寸（如 `800x600`）。
- **工具栏**：
  - 复制到剪贴板（`Enter` 或双击）、保存（`Ctrl+S`）、贴到屏幕
  - 识别文字、识别二维码、长截图、退出
- **标注**：画笔、荧光笔、直线、箭头、矩形、椭圆（按住 Shift 画正形）、文字、序号、马赛克、模糊。
  - 颜色可以自定义，线条有细 / 中 / 粗三档，矩形和椭圆可以填充。
  - `Ctrl+Z` 撤销，`Ctrl+Y` 重做，`Delete` 删除选中的标注。
- **长截图**：点长截图后，在区域里慢慢向下滚动，程序会自动拼接，最后点「完成」。
- **延时截图**：托盘或工具箱里有「3 / 5 / 10 秒后截图」，适合截菜单。

### 贴图

截图后点「贴到屏幕」，图片会浮在所有窗口最上面。

- **操作**：拖动移动，滚轮缩放，`Ctrl+滚轮` 调透明度，双击或 `Esc` 关闭。
- **右键菜单**：复制、保存...、标注...、识别文字、识别二维码、原始大小、透明度、鼠标穿透、关闭、关闭全部贴图。
- **鼠标穿透**：开启后贴图点不到，要用托盘「恢复贴图点击」或穿透快捷键关掉。

### 取色、颜色与标尺

- **取色**：移到目标处，单击复制颜色值，`Tab` 切换 HEX / RGB / HSL，`Esc` 退出。
- **颜色页**：颜色格式互转，记录最近取色，可以收藏，还有对比度检查（WCAG 2 的 AA / AAA 标准）。
- **标尺**：拖动测量像素距离，`C` 复制结果，`Esc` 退出。

### 截图历史

最近的截图保存在「截图历史」页，默认 50 张。可以打开、编辑、贴图、复制、删除、打开文件夹。

### 相关设置（设置 → 截图与屏幕工具）

- 截图时隐藏本程序窗口；延时截图等待的秒数。
- 文件名模板，默认 `截图_{yyyyMMdd_HHmmss}`。
- 每次截图后自动保存 PNG 到指定文件夹（留空时保存到 `图片\SeedToolBox`）。
- 截图历史保留张数（0 表示不记录）。
- 文字识别语言；识别后直接复制、不弹结果窗口。
- 翻译网址（`{text}` 会被替换成识别出的文字）。

## 6. 文字识别与二维码

- **识别文字（OCR）**：在截图里按 `O`，或用托盘 / 快捷键「识别文字」。
  - 程序自带离线 PaddleOCR（中英文），不联网也能用。它加载不了时，改用 Windows 自带 OCR。
  - 结果窗口：复制、翻译（先在设置里填翻译网址）、打开链接、交给 AI。
- **识别表格**：结果按 Tab 分隔，直接粘贴到 Excel 或 Word 就是表格。
- **二维码**：
  - 截图里按 `Q` 识别；也可以「全屏扫码」，识别屏幕上所有二维码。
  - 「生成二维码」可选小 / 中 / 大三种尺寸，可以复制图片、保存或贴到屏幕。

## 7. 录屏

1. 按 `Alt+Shift+E`，选择区域或窗口，点「开始录制」。开始前默认倒计时 3 秒。
2. 录制中可以暂停 / 继续。点「停止录制」或再按一次 `Alt+Shift+E` 结束。
3. 结束后打开编辑窗口：
   - 拖动时间轴两端裁剪首尾，`I` / `O` 设选区起点和终点，空格播放，`←` / `→` 逐帧。
   - 可以删除选中帧、设置帧延迟、撤销编辑。
   - 点「导出…」，选 MP4 视频或 GIF 动图，并设帧率和尺寸。

**录屏设置**：帧率（默认 30）、画质、录制系统声音、录制麦克风、显示鼠标指针和点击效果、在视频里显示按下的按键（注意：密码也会显示）、GIF 默认帧率和尺寸。

## 8. 剪贴板历史

程序会自动记录复制过的文字、富文本、文件和图片，最多 300 条，置顶的不计入。

### 快速粘贴

按 `Alt+Shift+V`，列表出现在鼠标位置：

| 按键 | 作用 |
|---|---|
| `Enter` | 粘贴 |
| `Shift+Enter` | 粘贴为纯文本 |
| `1`–`9` | 粘贴对应那一条 |
| `Ctrl+单击` | 多选，合并粘贴 |
| `Ctrl+P` | 置顶 |
| `Delete` | 删除 |

### 剪贴板页

- **搜索**：输入“图片”“文件”只看这一类，`#标签` 按标签搜。
- **操作**：复制、复制为纯文本、合并复制、置顶、编辑、标签、删除、清空未置顶、导出（JSON / TXT）。

### 隐私

- **暂停记录**：托盘里点「暂停记录剪贴板」。
- **忽略程序**：来自这些程序的内容不记录，默认有 KeePass、KeePassXC、1Password、Bitwarden，可以自己加。
- 密码管理器标记为“不记录”的内容会自动跳过。
- 设置里可以让未置顶记录 N 天后自动删除。

## 9. 便签与快速笔记

- **新建便签**：按 `Alt+Shift+N`，桌面上出现一张便签，内容自动保存。
  - 按钮：新建（`Ctrl+N`）、收起（`Ctrl+W`）、置顶、颜色（黄 / 蓝 / 绿 / 粉 / 紫 / 灰）、删除。
  - 重启程序后，之前打开的便签会自动恢复。
- **快速笔记页**：所有便签都在这里，可以新建、搜索、贴到桌面 / 从桌面收起、全部显示 / 隐藏、复制、删除。

## 10. 提醒

直接用中文写时间，在「提醒」页或启动器搜索框里输入都可以：

```
25分钟后 休息一下
1小时30分后 开会
下午3点半 打电话
明天9点 交报告
周五 18:00 写周报
5月20日 纪念日
每天 8:30 打卡
工作日 9点 站会
```

也支持 `1h`、`30m` 这样的简写，以及“每周X”重复。

- 到点后提醒在屏幕右下角弹出，可以点「知道了」，或延后 5 分钟、10 分钟、1 小时。
- 程序没运行时错过的提醒，下次启动会列出来。

## 11. AI 助手

AI 助手基于开源的 pi 智能体，要用你自己的模型 API Key 或订阅。

### 首次配置

1. 打开「设置 → AI 助手」，勾选「开启 AI 助手」。
2. 「pi 来源」选「内置」，点「下载安装 pi」（约 40 MB）。
   - 下载源默认是 npmmirror（阿里），也可以换成华为云、腾讯云、官方源或自定义源；勾选「失败时自动换其他源」更稳。
   - pi 装在程序目录的 `Runtime\pi`，不改系统 PATH。
3. 在「模型服务」里选一个服务商，填 API Key：
   - **内置服务商**：DeepSeek、智谱 GLM、Kimi、MiniMax、通义千问、小米 MiMo、OpenRouter、OpenAI、Anthropic Claude、Google Gemini、xAI Grok、Groq、Mistral。
   - **OpenAI 兼容接口**：百炼、硅基流动、火山方舟（豆包）、月之暗面、智谱开放平台、本机 Ollama、LM Studio，或选「其他」自己填接口地址、模型名和 Key。
   - **订阅登录**：点「打开 pi 终端」，输入 `/login`，可以登录 Claude、ChatGPT、Copilot 等订阅。
4. 选好「当前模型」，需要的话调「推理强度」。

### 使用

- **打开方式**：
  - 托盘或主窗口的「AI 助手」、启动器输入 `ai 问题`
  - 快捷键「AI 处理选中文字」「截图问 AI」
  - 文字识别结果里的「交给 AI」
- **对话**：可以粘贴或拖入图片，也可以截图附上。窗口里有「新对话」「停止」「复制回答」按钮。
- **自动化模式**：AI 可以操作电脑。
  - 能做的事：整理文件、查找文件、读写文本、查看进程和端口、截图识字、读写剪贴板、调音量和亮度、加提醒和笔记、运行 PowerShell 命令。
  - **每个改动类操作都会先请你确认**，可以选「允许」「拒绝」或「本次对话都允许」。
  - AI 只能改「允许 AI 改动的文件夹」里的文件，默认是桌面、文档和下载。
  - 运行 PowerShell 要单独在设置里打开，每条命令都要确认。
- **快捷任务**：常用的请求可以「存为快捷任务」，右键「定时运行…」可以设成“每天9点”这样的定时任务。
- **AI 操作记录**：自动化做过的每个改动都记在这里。移动、复制、新建、写入的文件和添加的提醒、笔记都能「撤销」；删掉的文件在回收站里。
- **插件和技能**：在「AI 插件和技能」页操作。
  - 从插件市场搜索安装，也可以按 `npm:包名`、`git:地址` 或本地路径安装。
  - 技能放进技能文件夹（每个技能一个带 `SKILL.md` 的文件夹），在对话里用 `/skill:名字` 调用。
  - 要接入 MCP 服务器，安装 `npm:pi-mcp-adapter`。

**提示**：
- API Key 保存在本机的 `Data\PiAgent`，不会被同步到云端。
- 开发工具里的 API 请求、终端里的「AI 生成命令」「用 AI 解释」也用这里的配置。

## 12. 开发工具

在工具箱侧边栏的「格式与编码」「开发调试」「图片」「文件」「系统与网络」分组里。

### API 请求（类似 Postman）

- **标签页**：多标签，`Ctrl+T` 新建，`Ctrl+W` 关闭。
- **请求编辑**：参数、认证、请求头、请求体、前置脚本、测试、设置、说明。
  - 设置里可以改超时和代理，关闭 SSL 证书校验，控制是否跟随重定向。
- **环境与变量**：URL 和请求体里用 `{{变量}}`，在「管理环境」「全局变量」里维护，敏感值可以设为机密变量。
- **脚本**：前置脚本和测试用 JavaScript，支持 `pm.test`、`pm.expect`、`pm.environment`。
- **集合**：集合 / 文件夹 / 历史三栏。文件夹和集合可以设公共的认证、脚本和变量。
- **运行集合**：可以设轮数、数据文件（CSV / JSON）、请求间隔、出错就停止。
- **导入导出**：从 Postman 集合 / 环境或 cURL 导入，可导出为 Postman v2.1。
- **生成代码**：cURL、fetch、Python、C# 等。
- **AI**：AI 生成请求、AI 解释响应、AI 写测试。

### 文本对比

- 左右各粘贴一段文本，或者拖入文件，点「比较」。
- 可以左右并排、只显示差异、忽略大小写、忽略行首尾空白、上一处 / 下一处跳转、导出补丁。

### 格式与编码

- **代码格式化**：JSON / JavaScript / CSS / XML / HTML / SQL / YAML 的格式化、压缩和校验。JSON 还可以排序键、看树视图、做 JSONPath 查询、转义和反转义。
- **数据格式互转**：JSON / XML / YAML / CSV / TOML / INI 互转；JSON 可以生成 C# / TypeScript / Java / Go 类型和 JSON Schema。
- **编码转换**：URL、Unicode 转义、HTML 实体、十六进制、Punycode、Quoted-Printable、ROT13。
- **Base64 编解码**：Base64 / Base32 / Base58，支持 URL 安全格式，文件可以编码，也可以把解码结果存成文件（上限 20 MB）。
- **时间戳/进制**：
  - 时间：Unix 时间戳与日期互转，时区换算，计算日期间隔和工作日。
  - 数字：进制互转，查看位视图，拆解 IEEE-754 浮点数。

### 开发调试

- **正则测试**（.NET 语法）：实时高亮、分组、替换预览、速查表、常用正则、收藏。
- **JWT 解码 / 校验**：查看头部和载荷，校验签名，并提示弱密钥和 `alg=none`。也能签发 HS* Token。
- **哈希校验**：MD5、SHA 系列、SHA3、CRC、xxHash64、HMAC，可以比对期望值，批量计算文件夹，读写校验文件。
- **UUID/密码**：生成 UUID v1/v4/v5/v7、ULID、NanoID、随机密码、密码短语、Lorem Ipsum。

### 图片

- **图片格式转换**：PNG / JPG / BMP / GIF / TIFF / ICO 批量转换，可以缩放、旋转、按 EXIF 转正、去掉元数据。
- **图片 Base64**：图片转 Base64 或 Data URI，也能反过来还原成图片。

### 文件

- **批量重命名**：
  - 方式：查找替换、正则、模板（`*` 原名，`#` 序号，`{date:…}` 日期，`{exif:…}` 照片信息）、大小写转换。
  - 执行前先预览，执行后可以撤销上一次。
- **重复文件**：按内容查找（也可以只按文件名），每组保留最新或最早的一个，其余移到回收站。
- **空间占用**：按文件夹统计大小，有树状图、按扩展名统计、最大的 100 个文件，可以导出 CSV。
- **文件压缩**：
  - 精简代码：压缩 JS / CSS / HTML / SVG / JSON。
  - 压缩图片：PNG 转 8 位色，JPG 重新压缩，只有变小了才保留。
  - ZIP：打包和解压。

### 系统与网络

- **端口/网络**：
  - 端口：查看端口占用（可以结束占用的进程）、端口扫描。
  - 网卡与连通：网卡与 IP、公网 IP、Ping / 端口测试、路由追踪。
  - 其他：DNS 查询、子网计算、HTTP 请求。
- **Hosts 管理**：
  - 编辑：列表和文本两种方式，每条可以单独启用或停用。
  - 方案：可以存成方案，一键切换。
  - 保存：需要管理员权限，保存后自动刷新 DNS 缓存，也可以从备份恢复。

## 13. 终端 / SSH

从主窗口「终端 / SSH」或托盘打开，终端在单独的窗口里。需要 WebView2 运行时。

### 主机管理

- **新建主机**：左侧主机列表点「新建主机…」。
  - 基本信息：名称、地址、端口、用户名。
  - 登录方式：密码、私钥（可带口令）或键盘交互（验证码 / 二次验证）。
  - 连接：登录后自动执行的命令、跳板机、代理、保活间隔、断线自动重连、字符编码。
  - 外观：标签颜色、配色、备注、分组。
- **支持的协议**：SSH、Telnet、串口、FTP / FTPS，以及本地终端（PowerShell、cmd、WSL、Git Bash 等）。
  - FTP 主机打开的是独立的文件窗口。
  - 串口可以设波特率、数据位、停止位、校验、流控。
- **分组**：分组可以多级，名称里用 `/` 分隔，如 `公司/测试`。
- **右键主机**：
  - 连接：连接、连接并打开 SFTP、连接并打开监控、全部连接。
  - 管理：复制一份、设为默认、重命名、删除。
  - 其他：复制 ssh 命令、在系统终端中打开 ssh。
- **导入**：「导入主机」可以从 `~/.ssh/config`、Xshell（Sessions 文件夹）、FinalShell（conn 文件夹）导入。密码不会导入，已存在的会跳过。
- **主机指纹**：第一次连接要确认主机指纹；指纹变化时会警告，防止中间人攻击。
- **密码安全**：密码和私钥口令用 Windows 加密保存，只有当前 Windows 用户能解开。

### 终端操作

| 操作 | 方法 |
|---|---|
| 复制 / 粘贴 | `Ctrl+Shift+C` / `Ctrl+Shift+V`（也可以设置选中即复制、右键粘贴） |
| 查找 | `Ctrl+Shift+F`，支持区分大小写和正则 |
| 缩放字体 | `Ctrl+加号` / `Ctrl+减号` |
| 分屏 | 左右分屏 / 上下分屏，最多 4 个 |
| 广播输入 | 「广播输入到所有分屏」，一次在多台机器上执行 |
| 同一连接多开 | 「新建终端（共用这条连接）」，秒开，不用重新登录 |
| 自动补全 | 输入时根据历史和片段提示，按 `→` 或 `Tab` 采用 |
| rz / sz | 服务器上装了 lrzsz 就能用 ZMODEM 上传下载 |

- **标签右键**：复制会话、重命名、关闭其他 / 右侧会话、重新连接、重置终端、清屏。
- **多行粘贴**：粘贴多行内容前会先确认，防止误执行。
- **会话日志**：可以把会话记录到文件，默认存在 `Data\TerminalLogs`。
- **终端设置**：
  - 外观：字体、字号、行高、光标样式、回滚行数。
  - 配色：默认深色 / 浅色、Solarized、Dracula、One Dark、Monokai、Nord。

### 右侧面板

终端右侧的竖栏可以切换这几个面板：

- **文件（SFTP）**：
  - 浏览：输入路径跳转，收藏常用文件夹，显示隐藏文件；「定位」可以跟随终端的当前目录。
  - 上传下载：直接把本地文件或文件夹拖进来就是上传。下载的文件夹默认进下载目录。
  - **文件夹自动打包**：服务器有 tar 时，文件夹会先打成一个 tar.gz 传过去、自动解压、删掉压缩包，比逐个文件传快得多。没有 tar 或用 FTP 时自动改为逐个文件传。
  - **文件已存在**：会问你覆盖、跳过还是全部取消，可以勾选“后面的冲突都这样处理”。
  - 编辑：远程文件用本地编辑器打开，保存后自动上传。
  - 比较：与本地文件比较，或者先「标记用于比较」，再和另一台服务器上的文件比较。
  - 其他：新建、重命名、删除、修改权限、复制路径、在终端中进入。
- **传输**：
  - 所有上传下载都列在这里，显示进度、速度和所在服务器；传输进行时，侧栏按钮上会显示正在传的数量。
  - 双击打开文件。右键可以在文件夹中显示、复制路径、重试失败的、取消、清除已结束的。
  - 顶部可以打开下载目录。
- **监控**：每 2 秒刷新负载、CPU、内存、交换、磁盘、网速，进程按 CPU 排序，右键可以结束进程。
- **Docker**：
  - 容器：启动、停止、重启、暂停、删除，进入容器，查看日志和详情。
  - 镜像：拉取、运行、查看构建历史、删除。
  - 权限不够时可以用 sudo 执行。
- **命令片段 / 历史命令**：
  - 片段：常用命令存成片段，可以带参数 `{{名称:默认值}}`，一键插入、执行或发到所有分屏。
  - 历史：历史命令按主机记录。
- **端口转发**：本地转发（-L）、远程转发（-R）、动态转发 / SOCKS 代理（-D），可以设成随连接自动启动。

### AI

- **「AI 生成命令…」**：用中文描述要做的事，AI 生成命令。生成后只放进输入行，**不会自动执行**。
- **「用 AI 解释」**：选中一段输出或报错，让 AI 解释。

## 14. 系统工具

- **保持唤醒**：阻止电脑休眠，可以一直保持，也可以只保持一段时间（1 分钟到 7 天），还可以同时让屏幕常亮。
- **窗口置顶**：让任意窗口保持在最上层，快捷键「切换当前窗口置顶」最方便。
- **环境变量**：
  - 可以编辑用户变量和系统变量（系统变量需要管理员权限）。PATH 可以按列表编辑，并检查重复和不存在的路径。
  - 每次保存前自动备份。
- **启动项**：管理注册表里的开机启动项和启动文件夹。禁用时会把项目备份起来，之后可以恢复。
- **进程**：筛选进程、结束进程、打开文件位置、自动刷新、导出 CSV。
- **本地服务**：把常用的开发命令（如 `npm run dev`）存起来，一键启动 / 停止、看日志、打开网址。
  - 可以设成 SeedToolBox 启动时自动运行。
  - 退出 SeedToolBox 时，这些服务会一起停止。
- **系统监控**：桌面悬浮条显示 CPU、内存、显卡占用和网速，可以调不透明度、开鼠标穿透。
- **声音与亮度**：切换输入输出设备，调各程序的音量，静音麦克风，调屏幕亮度（外接显示器要支持 DDC/CI）。

## 15. 同步

在多台电脑之间同步笔记、剪贴板、启动器和设置，走 WebDAV（坚果云、Nextcloud、群晖等都行）。

1. 打开「设置 → 同步」，填服务器地址、账号、密码、云端文件夹。
   - 坚果云：地址填 `https://dav.jianguoyun.com/dav/`，密码要用坚果云的「应用密码」，不是登录密码。
2. 设一个**同步密码**。数据上传前会用它加密，每台电脑都要填同一个。**忘了就没法解密**，只能换个云端文件夹重新同步。
3. 选同步内容：快速笔记、剪贴板历史（可以选择是否包括图片）、启动器项目、其他设置和快捷键。
4. 选同步方式：只在手动时同步，或每 N 分钟自动同步。另有「立即同步」按钮。

**注意**：
- AI 的 API Key 不会同步，每台电脑要各自配置。
- 从云端拿到的启动器项目和设置，重启程序后生效。

## 16. 数据、备份与迁移

所有数据都在程序目录的 `Data\` 下：

| 文件 / 文件夹 | 内容 |
|---|---|
| `launcher.json` | 启动器分组和项目 |
| `terminal.json` | 终端主机、片段和终端设置 |
| `api.json` | API 请求集合和环境 |
| `ai.json`、`PiAgent\` | AI 设置和模型 Key |
| `notes.json` | 便签 |
| `reminders.json` | 提醒 |
| `clipboard.json`、`Clipboard\` | 剪贴板设置和历史 |
| `screentools.json`、`captures\` | 截图设置和截图历史 |
| `Backups\` | 自动备份 |
| `Logs\` | 运行日志 |

- **自动备份**：每天启动时自动备份一次，存在 `Data\Backups\`，保留最近 7 份。
- **手动备份**：在「设置 → 数据」里点「备份数据…」，打包成 zip。不含日志、剪贴板历史和旧备份。
- **恢复**：「恢复数据…」，选一个备份 zip。恢复前会自动把当前数据再备份一份，恢复后程序自动重启。
- **换电脑 / 换目录**：
  1. 先退出程序（托盘 → 退出）。
  2. 把整个 `Data\` 文件夹复制到新的程序目录。
  3. 同一台电脑、同一个 Windows 用户下，保存的密码可以直接用。换电脑或换用户后，终端里保存的密码要重新输入，因为它们是用当前 Windows 用户加密的。

## 18. 常见问题

**快捷键没反应**
可能被别的程序（QQ、微信、输入法等）占用了。启动时托盘会提示，到「设置 → 快捷键」换一个。

**终端打不开，提示缺少 WebView2**
按提示的链接安装 Microsoft Edge WebView2 运行时，装好后重新打开终端。

**SSH 连接失败**
- 先检查地址、端口、用户名。
- 需要跳板机的主机，在主机设置的「跳板机」里选好。
- 指纹变化的警告要认真看：服务器重装过的话可以接受新指纹，否则可能有人在拦截连接。

**文件夹上传没有打包**
只有 SSH 连接、服务器上有 `tar` 时才打包。FTP 或没有 tar 的服务器会逐个文件传，结果一样，只是慢一些。

**文字识别不准或没结果**
- 尽量截清晰的区域。
- 在「设置 → 截图与屏幕工具」里指定识别语言试试。

**AI 助手用不了**
- 确认已勾选「开启 AI 助手」，并已「下载安装 pi」。
- 确认已填好模型服务的 API Key，并选了「当前模型」。
- 下载失败时换一个下载源，或勾选「失败时自动换其他源」。

**录屏没有声音或无法录制**
- 检查录屏设置里是否勾选了系统声音 / 麦克风。
- Windows N 版要先安装媒体功能包。

**出问题了怎么反馈**
日志在 `Data\Logs\app.log`，反馈时附上它。
