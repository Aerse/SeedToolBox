# 批量重命名

1. 用 list_folder 列出文件，确认范围（扩展名、是否含子文件夹）。
2. 先列一张“原名 → 新名”对照表给用户看（最多展示 20 行，其余说明总数），检查新名字不重复、不含 `\ / : * ? " < > |`。
3. 用户确认后，用一次 move_files 完成全部改名（from 和 to 在同一文件夹）。
4. 序号按用户要求的排序方式（名称/修改时间），位数补零，例如 001。
5. 完成后提醒可以在“AI 操作记录”里一键撤销。
