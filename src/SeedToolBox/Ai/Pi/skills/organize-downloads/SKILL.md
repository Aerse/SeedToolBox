# 整理文件夹

1. 用 list_folder 看清目标文件夹（默认是用户的“下载”），统计各类文件的数量和大小。
2. 先给出方案再动手：按类型归到 `图片`、`文档`、`压缩包`、`安装包`、`视频`、`音频`、`其他` 子文件夹；超过 90 天的安装包列出来建议删除。
3. 用户同意后，用 create_folder 建子文件夹，再用一次 move_files（items 里放全部移动项）批量移动，不要一个一个调用。
4. 同名冲突时在文件名后加 ` (2)`，不要覆盖。
5. 删除只用 delete_files（进回收站），而且只删用户明确同意的。
6. 最后汇报移动了多少个文件，提醒可以在“AI 操作记录”里撤销。
