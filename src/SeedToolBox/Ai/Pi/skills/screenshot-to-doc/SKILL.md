# 截图转文档

1. 用户给了图片时直接看图；需要准确文字时用 recognize_text（表格用它的表格模式）。
2. 保留原有结构：标题、列表、表格。表格输出为 Markdown 表格，或用户要求时输出 CSV。
3. 看不清的地方标成 `[?]`，不要编造。
4. 问清保存位置和文件名（默认存到“文档”，扩展名 .md），用 write_text_file 保存；已有同名文件时先问是否覆盖。
5. 也可以按用户要求用 set_clipboard 直接放到剪贴板。
